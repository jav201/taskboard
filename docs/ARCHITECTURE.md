# Architecture — module map — taskboard

> **Artifact language.** Canonical **English scaffold**; generate in the project's language.

> **Owed in.** `core` by trigger · `full` ✓
> **No reserved-field block.** What a rule reads out of this artifact is `V8`'s `` `path/**` `` **globs** — paths, not words — so there is no label here for a translation to lose (the population and its reasons live in `LANG RESERVED-population-closed`).
> **Source:** `/dev-flow-init` step 4's seed-by-level table, which is this fact's one home. A level marked `—` **does not owe this artifact, and its absence is not an omission**; `by trigger` means the station exists only when the `triggers` block fired, and `stations_active` in `state.json` is the authority for *this* batch. Where a SECTION or a gate row is owed more narrowly than the artifact, it says so on the row.

> **Home: the REPO** (`docs/ARCHITECTURE.md`), versioned beside the code — **not** the vault. It is the
> **oracle** the A-family triggers read: from a document store no mechanical check could open it.
> It is a **standing project artifact**, not a per-batch one: batches amend it, they do not recreate it.

> **Distilled from IEEE 1016 by one selection rule: a viewpoint enters this map only if it FEEDS A
> TRIGGER.** In: **Composition** (A1/A2 + the source-file budget) · **Dependency** (A3 + parallelisation)
> · **Interface** (A3 + output-then-consume) · **Context** (the security family). Out — they belong in
> the design proposal, and only when they apply: Logical · Information · Patterns · Structure ·
> Interaction · State Dynamics · Algorithm · Resource. Keeping the other eight out is deliberate: a map
> that tries to describe everything stops being checkable, and a map that is not checkable is prose.

## 1 · Context — the system boundary

taskboard is a local, single-user terminal app. Everything it touches crosses one of these lines.

| External actor / service | Direction | What crosses | Notes |
|---|---|---|---|
| the operator's terminal | in / out | key presses, the painted screen | Textual; the only interactive surface |
| the board file `board.json` (default `~/.taskboard/board.json`) | in / out | projects, tasks, settings | read at mount and at every board switch, written on every mutation (`Board.save`); a corrupt file is quarantined; `taskboard --open PATH` opens any board file outside the registry, read-write, without registering it (batch 2026-10-20-batch-03) |
| the boards registry `boards.json` beside the default board (`~/.taskboard/boards.json`) | in / out | per board: id, name, colour, path, last opened, archived; the last board opened | read at start (`boards.Registry.load`, never raising; a missing file is a registry of the default board alone, `Main`); written atomically only when it changes — a second board registered or created, a switch, a rename, an archive (batch 2026-10-20-batch-01) |
| the board folders `~/.taskboard/boards/<id>/` | in / out | a created board's file (and, beside it, its own history, images, reports) | `boards.Registry.create`; one folder per board, never overwritten (batch 2026-10-20-batch-01) |
| a project move's records beside each board file | out | `<board file>.pre-move-<date>[-N]` and, beside the source, `history.jsonl.pre-move-<date>[-N]` (byte copies taken before anything is written; the history's streamed, batch 2026-10-20-batch-02) and `move-<date>.json` (a list of moves: project, from, to, tasks, links kept, links dropped; a file there that is not a list is left alone and `move-<date>-<N>.json` takes the entry) | `boards.move_project` (batch 2026-10-20-batch-01) |
| lock files `boards.json.lock`, `<board file>.lock`, `people.json.lock` (batch 2026-10-21-batch-01), `marks.json.lock` (batch 2026-10-24-batch-01) beside the file they guard | in / out | a random token | `boards.file_lock`: created exclusively while taskboard reads, changes and writes the registry (every write) or a move's target board; removed on exit only while it holds its token; a regular lock file more than 10 s from now is a dead instance's and taken over; a wait past 2 s is an `OSError` naming the file busy (batch 2026-10-20-batch-02) |
| presence markers `~/.taskboard/open/<16 hex of the board file's key>-<32 hex token>.json` | in / out | `{"since", "pid"}` | one per window per open board: `boards.announce` creates it exclusively when a board opens, the app renews it every 30 s and `boards.withdraw` removes it when the board is left or the app exits; `boards.open_elsewhere` reads another window's to warn once, and removes a regular marker of that board not renewed for 120 s (a dead window's); never a lock; in the home `~/.taskboard/` (Main's folder, beside `boards.json` and `boards/`), never another board's folder (batch 2026-10-20-batch-03) |
| the people directory `people.json` beside the registry (`~/.taskboard/people.json`) | in / out | per person: handle (`id`), name, role, note | `people.Directory`: read at start, never raising (an unreadable file copied to `people.json.corrupt`, the directory empty, one notice); written only when a person is added or edited, atomically under `people.json.lock` (`boards.file_lock`) as a read-modify-write; one directory for every board; never pushed to a team folder — a mention travels in a note as its `@handle` text (batch 2026-10-21-batch-01) |
| the marks directory `marks.json` beside the registry (`~/.taskboard/marks.json`) | in / out | per class: id, name, shape, colour, `hidden` | `marks.Directory`: read at start beside `people.json`, never raising (an unreadable file copied to `marks.json.corrupt`, the directory empty, one notice); written only when a class is added, edited or hidden, atomically under `marks.json.lock` (`boards.file_lock`) as a read-modify-write; one directory for every board; starts empty — no seeded classes; never pushed to a team folder — a task's `mark` field travels unchanged (batch 2026-10-24-batch-01) |
| the board's `reports/` folder | out | presentation SVG/PNG, the HTML report | `views.present_paths`, `report.py`; view 3's export carries no cursor and ends at its last row of content (batch 2026-10-20-batch-03) |
| the open board's `reports/` folder — the two HTML reports (batch 2026-10-29-batch-01) | out | `workspace-<date>.html` (variant B) and `deck-<date>.html` (variant C); scope `p` inserts the board and project slugs (`workspace-<board slug>-<project slug>-<date>.html`, `report_path`'s slug rule held in `report_html.slug`) — every loaded board's facts, the workspace's embedded as script-safe JSON | `report_html.write_reports`, from the `H` modal; written beside the OPEN board's file only; a same-day export overwrites; the boards are only read |
| the OS default handler (the browser) | out | the path of the report the export just wrote | `o` while the export's toast lives (10 s): `os.startfile` on Windows, else `webbrowser.open(path.as_uri())`; no other path is ever passed (batch 2026-10-29-batch-01) |
| a recipient's browser (outside the app) | in / out | the workspace's view in its URL hash; `workspace-view-<date>.html`, the filtered download | written by the workspace page's own code (a Blob download), never by the app; the downloaded file holds only the kept tasks; the pages make 0 network requests (batch 2026-10-29-batch-01) |
| `history.jsonl` beside the board | out | the transition log | `history.py` |
| a shared team folder (`team.json`, `user-*.json`) | in / out | team projects' tasks | `team_sync.py`; personal tasks never leave; nor do the people directory (a mention is the note's `@handle` text; batch 2026-10-21-batch-01) or the marks directory (a task's `mark` field travels unchanged; batch 2026-10-24-batch-01) |
| Microsoft Edge (headless) | out | the SVG to rasterise | `views.save_present_png`; absent → SVG only |
| the clipboard | in | text, images | the editors' paste |
