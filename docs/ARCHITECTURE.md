## 1 · Context — the system boundary

taskboard is a local, single-user terminal app. Everything it touches crosses one of these lines.

| External actor / service | Direction | What crosses | Notes |
|---|---|---|---|
| the operator's terminal | in / out | key presses, the painted screen | Textual; the only interactive surface |
| the board file `board.json` (default `~/.taskboard/board.json`) | in / out | projects, tasks, settings | read at mount and at every board switch, written on every mutation (`Board.save`); a corrupt file is quarantined |
| the boards registry `boards.json` beside the default board (`~/.taskboard/boards.json`) | in / out | per board: id, name, colour, path, last opened, archived; the last board opened | read at start (`boards.Registry.load`, never raising; a missing file is a registry of the default board alone, `Main`); written atomically only when it changes — a second board registered or created, a switch, a rename, an archive (batch 2026-10-20-batch-01) |
| the board folders `~/.taskboard/boards/<id>/` | in / out | a created board's file (and, beside it, its own history, images, reports) | `boards.Registry.create`; one folder per board, never overwritten (batch 2026-10-20-batch-01) |
| a project move's records beside each board file | out | `<board file>.pre-move-<date>[-N]` (a byte copy taken before anything is written) and `move-<date>.json` (a list of moves: project, from, to, tasks, links kept, links dropped; a file there that is not a list is left alone and `move-<date>-<N>.json` takes the entry) | `boards.move_project` (batch 2026-10-20-batch-01) |
| the board's `reports/` folder | out | presentation SVG/PNG, the HTML report | `views.present_paths`, `report.py` |
| `history.jsonl` beside the board | out | the transition log | `history.py` |
| a shared team folder (`team.json`, `user-*.json`) | in / out | team projects' tasks | `team_sync.py`; personal tasks never leave |
| Microsoft Edge (headless) | out | the SVG to rasterise | `views.save_present_png`; absent → SVG only |
| the clipboard | in | text, images | the editors' paste |

## 5 · Rationale — the decisions, and why

| Decision | Alternative rejected | Re-open when |
|---|---|---|
| renders live in `views` as pure functions over a `Board` | rendering inside widgets | a render needs live widget state it cannot take as an argument |
