Focus Board — prototipos

Vista nueva para seguimiento y recolección de detalles: solo las tareas marcadas (pinned) aparecen aquí. Cada fila muestra fechas, notas, imágenes, URLs y un set de emoji rápidos. El usuario puede pintar palabras en amarillo, rojo o verde para resaltar decisiones, bloqueos o acuerdos.

❗ alerta / bloqueo ❓ duda pendiente ⭐ importante ⏰ vencimiento cercano 📋 tiene notas ☑ hecho / ☐ pendiente
Bindings propuestos: t pin/unpin tarea seleccionada · T pin/unpin proyecto completo · i abrir visor de imágenes de la tarea · o abrir imágenes/URLs en app del sistema · enter abrir detalles (ya existe) · esc salir del focus board. El flag también se edita en el modal de tarea como checkbox [ ] pinned.

Cada tarea es una tarjeta vertical. Buena para leer notas largas y ver muchos metadatos a la vez.

Variante D — Image-first board

Las tareas con imágenes se muestran con una miniatura visible siempre; las que no tienen imagen quedan en una lista secundaria. Útil cuando las imágenes son la señal principal (diseño, bugs visuales, screenshots).

Recomendación de diseño

Usa A cuando…

El uso principal es leer: notas largas, contexto, imágenes como adjunto visible. Menos tareas en pantalla pero más información por tarea.

Usa B cuando…

El uso principal es rastrear muchas tareas a la vez: daily standup, revisión rápida. Las imágenes se indican con contador; no se previsualizan.

Usa C cuando…

El uso principal es investigar una tarea: notas completas, checklist e imágenes en un panel de preview. Requiere más ancho.

Usa D cuando…

El uso principal es revisar material visual: screenshots, mockups, fotos. Las tareas con imagen lideran la vista; las demás quedan abajo.

Decisiones pendientes

  • ¿Tecla para entrar a la vista? Propuesta: 5 o ctrl+f.
  • ¿Nombre del flag? pinned, tracked, followed o starred.
  • ¿Los highlights de color se guardan en la tarea o son decoración temporal?
  • ¿La vista incluye tareas archivadas pinned o solo activas?
  • ¿Mostrar miniaturas reales inline (requiere terminal gráfica: WezTerm) o solo indicadores?
  • ¿En el inspector, preview de todas las imágenes o solo la primera?
  • ¿Variante D separa por "con/sin imagen" o filtra solo las que tienen imagen?
