# Requirements — taskboard — Inc C, multicolour notes (dev-flow-v3-beta)

> Strict EARS (five forms only), ISO/IEC/IEEE 29148. One `shall` per requirement. Each carries a
> numeric pass threshold and a negative control (a mutant that turns its test RED). Ids continue
> the repo's sequence in a fresh block: US-4201, HLR-4201..4206, LLR-4201.n..4206.n, TC-42nn, AT-42nn.
> Base: `0a8dfaa` (branch `feat/capture-list-colour`). Commission: `.dev-flow/COMMISSION-capture-list-colour.md` §Inc C (C-1..C-4).

## 1. Scope

**In:** the notes' colour syntax in the one tokeniser `views.highlight_segments`; every surface that
reads it (board/focus markup, details, editor preview, presentation, HTML workspace and deck and their
exports); the legends that list the syntax; the task editor's pens (`alt+1..6`, `alt+0`), the pen chip,
the live ink in the notes TextArea; the colour palette (`alt+c`, `1..6`, `0`, `esc`); the six tones'
terminal and HTML palette checks.
**Not in:** Inc L (list view, `Task.created`), Inc K (capture view). No data-model change: notes stay
plain text. No new dependency.

**Definitions.**

| Term | Meaning |
|---|---|
| code | one of `r o y g b v` (lower case only), pen order 1–6 |
| tone | the palette key a code maps to: `r`→`over`, `o`→`orange`, `y`→`soon`, `g`→`green`, `b`→`blue`, `v`→`violet` (all keys of `views.HEX`) |
| opener | `::<code>::`, plus at most one following space |
| closer | `::`, plus at most one preceding space, ending an open colour span |
| colour span | opener · inner text · (closer or line end or the next opener) |
| legacy span | `==…==` (`soon`), `!!…!!` (`over`), `++…++` (`green`) exactly as at base |
| span | a colour span or a legacy span |
| pen | the editor state "typing goes into an open colour span of code X" |
| lift (a pen) | the pen leaves its span by `alt+0`, another `alt+<n>`, or `alt+c` |
| target | for the palette: the selection, or the word (maximal run of non-whitespace) at the cursor |
| derived set | inputs generated by `itertools.product` over pieces, never a hand list (C-31) |

## 2. Source user story

**US-4201.** As the board's owner (`username_subject`) taking notes, I want to switch colour as easily as
switching pens in a notebook, and have every surface show those colours, so that my notes keep the
multicolour structure I use on paper. (Operator verdict 3: B + C; D4 objection: `::b:: … ::`.)

## 4. Low-level requirements

Each line: **id — form — statement.** Threshold. *NC:* negative control.

### 4.1 Tokeniser (`views.highlight_segments`) — HLR-4201

- **LLR-4201.1 — Ubiquitous.** The tokeniser shall map each colour span to one segment holding its inner text with the tone of its code.
  Threshold: for each of the 6 codes, `"::<c>:: x ::"` → `[("x", tone(c))]`; 6/6. *NC:* swap `b`→`violet`: 1 arm RED.
- **LLR-4201.2 — Ubiquitous.** The tokeniser shall drop at most one space after an opener and at most one space before a closer, as part of the markers.
  Threshold: `"a ::b:: x :: c"` → `[("a ","mut"),("x","blue"),(" c","mut")]`; `"::b::x::"` → `[("x","blue")]`; `"::b::  x  ::"` → `[(" x ","blue")]`; 3/3. *NC:* a mutant keeping the spaces yields `" x "` in arm 1.
- **LLR-4201.3 — Ubiquitous.** The tokeniser shall return, for every input holding no `::`, exactly the pairs the base `0a8dfaa` function returns.
  Threshold: 0 differences over the derived set of `tests/test_highlight_segments.py` (`PIECES` × up to 3). *NC:* map `==` to `blue`: RED.
- **LLR-4201.4 — Unwanted.** If a colour span is still open at the end of a line, then the tokeniser shall end the span at that line end.
  Threshold: `"::r:: open"` → `[("open","over")]`; `"::r:: a\nb"` → `[("a","over"),("\nb","mut")]` (the span never crosses `\n`); 2/2. *NC:* require a closer: arm 1 gives `[("::r:: open","mut")]`.
- **LLR-4201.5 — Unwanted.** If `::` stands where no opener matches and no colour span is open, then the tokeniser shall keep it as literal `mut` text.
  Threshold: `"std::vector"`, `"a :: b"`, `"::x:: t ::"`, `"::B:: t ::"`, `"::bb:: t ::"` each → one `mut` segment equal to the input; 5/5. *NC:* accept any letter: arms 3–4 RED.
- **LLR-4201.6 — State.** While a colour span is open, the tokeniser shall end it where the next opener starts, without dropping a space.
  Threshold: `"::b:: x ::r:: y ::"` → `[("x ","blue"),("y","over")]`. *NC:* lazy closer only: gives `("r:: y ::","mut")`.
- **LLR-4201.7 — Ubiquitous.** The tokeniser shall start the span whose start comes first in the line, and keep every marker inside a legacy span, and every legacy marker inside a colour span, as literal text of that span.
  Threshold: `"::b:: ==a== ::"` → `[("==a==","blue")]`; `"==a ::b:: c=="` → `[("a ::b:: c","soon")]`; 2/2. *NC:* nested tokenising: arm 1 RED.
- **LLR-4201.8 — Unwanted.** If a colour span has no inner text, then the tokeniser shall emit no visible character for it.
  Threshold: `"a::b::::c"` → joined segment text `"ac"`, and no segment holds `:`. *NC:* treat `::::` as literal: `":"` appears.
- **LLR-4201.9 — Ubiquitous.** The tokeniser shall return segments whose texts, joined, equal the input with the matched markers removed.
  Threshold: over a derived set of ≥ 1 000 inputs from pieces {`ab`,` `,`::b::`,`::r::`,`::`,`==y==`,`!!`,`::z::`,`é`,`\n`} × up to 4: 0 exceptions; joined text equals an independent oracle (the reference scanner in the test) for 100 %. *NC:* drop the text between two spans: RED.

- **LLR-4201.10 — Ubiquitous.** The tokeniser shall scan a line in time linear in its length.
  Threshold: a 100 000-char line of repeated `::b:: x :: ::` and one of repeated `std::` each tokenise in ≤ 250 ms, and t(100 000)/t(10 000) ≤ 20 (median of 3). *NC:* the re-search-every-loop scanner (SEC-1: 918 ms, ratio ≈ 100): RED.

### 4.3 Pens — HLR-4203

- **LLR-4203.1 — Event.** When `alt+<n>` (n = 1..6) is pressed while the notes field has the focus and no pen is on, the editor shall insert `::<code n>::` + two spaces + `::` at the cursor and place the cursor between the two spaces.
  Threshold: empty notes, `alt+5` → text `"::b::  ::"`, cursor `(0, 6)`. *NC:* insert without spaces: RED.
- **LLR-4203.2 — State.** While a pen is on, the editor shall keep each typed character inside that pen's span (exception, by design: a typed `::` is a closer — P-M1-5).
  Threshold: `alt+5`, type `abc` → `"::b:: abc ::"` and `highlight_segments` gives `[("abc","blue")]`. *NC:* cursor placed after the closer: RED.
- **LLR-4203.3 — Event.** When `alt+0` is pressed while a pen is on, the editor shall move the cursor to just after that span's closer.
  Threshold: `alt+5 abc alt+0 d` → `"::b:: abc ::d"`. *NC:* `alt+0` ignored: `d` lands inside.
- **LLR-4203.4 — Event.** When `alt+0` is pressed while a pen is on, the editor shall turn the pen off.
  Threshold: pen state `None` and chip `pen: none` after the press. *NC:* state not reset: RED.
- **LLR-4203.5 — Event.** When `alt+<m>` is pressed while pen n ≠ m is on, the editor shall move the cursor past n's closer and open m's span there.
  Threshold: `alt+1 ab alt+5 x` → `"::r:: ab ::::b:: x ::"`; segments `[("ab","over"),("x","blue")]`; rendered text `"abx"` = typed text. *NC:* m opened inside n: RED.
- **LLR-4203.6 — Unwanted.** If the pen is lifted while its span holds no inner text, then the editor shall remove that empty span.
  Threshold: `x` + `alt+2 alt+0` → `"x"`; `alt+2 alt+5 y` → `"::b:: y ::"`; 2/2. *NC:* keep the empty span: RED.
- **LLR-4203.7 — Event.** When `enter` is pressed while a pen is on and the mention picker offers no pick, the editor shall end the span before the line break and open the same pen's span after it.
  Threshold: `alt+5 ab enter cd` → `"::b:: ab ::\n::b:: cd ::"`; both lines tokenise `blue`. *NC:* plain newline: line 2 renders `cd ::` literal → RED.
- **LLR-4203.8 — Unwanted.** If the cursor leaves the pen's span (arrow keys, home/end, click, or a selection), then the editor shall turn the pen off.
  Threshold: `alt+5 ab`, then `right right right` (past the closer) → pen `None`; `left` inside the span → pen still on; 2/2. *NC:* pen survives leaving: RED.
- **LLR-4203.9 — Ubiquitous.** The editor's Notes label shall show the pen state (a chip in the pen's tone, or `pen: none`), the keys `1`..`6` in their tones, `0 off`, and `alt+c`.
  Threshold: at 118x30 and 80x24 the label's visible cells contain `1`..`6`, `0`, `alt+c` and the state, with 0 clipped key glyphs; at 118x30 the chip also names the pen (`blue`); 7 pen states × 2 sizes. *NC:* base label: RED.
- **LLR-4203.10 — Unwanted.** If `alt+<n>` or `alt+0` is pressed while the notes field does not have the focus, then the editor shall change no field.
  Threshold: focus on title, `alt+5` → title and notes byte-equal to before. *NC:* insert into the focused Input: RED.
- **LLR-4203.12 — Unwanted.** If `alt+<n>` is pressed while no pen is on and the cursor is inside a span (start < col < end), then the editor shall insert nothing and show the notice `Pens write new text — use alt+c to recolour.`
  Threshold: `"::r:: ab ::"`, cursor (0, 7), `alt+5` → text byte-equal, pen `None`, 1 notify. *NC:* insert the pair inside: RED.
- **LLR-4203.13 — Unwanted.** If `alt+<n>` is pressed while the notes' selection is not empty, then the editor shall insert nothing and show the same notice.
  Threshold: select `plan`, `alt+5` → byte-equal, 1 notify. *NC:* replace the selection: RED.
- **LLR-4203.14 — Unwanted.** If the cursor leaves the pen's span while it holds no inner text, then the editor shall remove that span.
  Threshold: `x` + `alt+3`, `home` → text `"x"`, pen `None`. *NC:* `"x::y::  ::"` left: RED.
- **LLR-4203.15 — Event.** When `alt+<n>` is pressed while pen n is already on, the editor shall change nothing.
  Threshold: `alt+5 ab alt+5` → `"::b:: ab ::"`, cursor (0, 8), pen `4`. *NC:* a second pair: RED.
- **LLR-4203.11 — Unwanted.** If the editor saves while a pen's span holds no inner text, then the editor shall save the notes without that empty span.
  Threshold: notes `x`, `alt+3`, `alt+s` → saved notes `"x"`. *NC:* saved `"x::y::  ::"` (strip keeps it): RED.

- **LLR-4203.16 — Ubiquitous.** The app shall receive `ESC` followed by a digit 0–6 from the terminal as the key `alt+<digit>`.
  Threshold: `XTermParser` fed `"\x1b5"` and `"\x1b0"` (after `taskboard.modals` is imported) yields keys `alt+5` and `alt+0`; 2/2. *NC:* base Textual table gives `∞`/`º`: RED.
- **LLR-4203.17 — Unwanted.** If a pen's inserted markers would change the line's visible text, then the editor shall insert nothing and show notice N4.
  Threshold: `"b:: x"` cursor (0,0) `alt+1` → byte-equal, 1 notify; `"C::b"` cursor (0,4) `alt+1` → byte-equal, 1 notify; 2/2. *NC:* insert anyway: RED.

### 4.4 Live ink — HLR-4204

- **LLR-4204.1 — State.** While the notes field holds a span (colour or legacy), the TextArea shall paint the span's inner text in `HEX[tone]`.
  Threshold: notes `"a ::b:: x :: c"`: the rendered cell of `x` has fg `#60a5fa`. *NC:* no highlight map: RED.
- **LLR-4204.2 — State.** While the notes field holds a span (colour or legacy), the TextArea shall paint its markers in `HEX["dim"]`.
  Threshold: cells of `::b::` and the closing `::` have fg `#5b6675`; 7/7 marker cells. *NC:* markers in tone: RED.
- **LLR-4204.3 — Event.** When the notes text changes, the TextArea shall rebuild its colours from the new text before the next paint.
  Threshold: type `y` into an open span → its cell is the tone after one `pilot.pause()`. *NC:* build only on mount: RED.
- **LLR-4204.4 — Ubiquitous.** The TextArea shall colour exactly the character ranges `highlight_segments` gives for each line.
  Threshold: over the derived set of LLR-4201.9 (single-line inputs), coloured ranges == tokeniser ranges for 100 %. *NC:* a second regex that ignores LLR-4201.6: RED.
- **LLR-4204.5 — Unwanted.** If a line holds non-ASCII text, then the TextArea shall still colour exactly the span's characters.
  Threshold: `"é ::b:: café ☕ ::"`: cells of `café ☕` blue, cell of `é` (col 0) not blue. *NC:* str offsets used as byte offsets: RED.
- **LLR-4204.6 — Unwanted.** If any other TextArea exists (the URLs and Images fields, any other screen), then the live ink shall leave its styles unchanged.

- **LLR-4204.7 — Ubiquitous.** The TextArea shall rebuild its colours in time linear in the text length.
  Threshold: a 100 000-char single line with 10 000 spans builds in ≤ 250 ms; t(100k)/t(10k) ≤ 20. *NC:* per-offset prefix re-encode: RED.
- **LLR-4204.8 — Unwanted.** If building the colours raises any exception, then the TextArea shall show the text without ink and keep working.
  Threshold: with `colour_spans` monkeypatched to raise, the editor opens, accepts typing and saves; 0 uncaught exceptions. *NC:* no fallback: the app crashes, RED.
- **LLR-4204.9 — Unwanted.** If the notes hold a lone surrogate code point, then the TextArea shall still open and colour the other spans.
  Threshold: notes `"\ud800 ::b:: x ::"` → editor opens, cell of `x` blue. *NC:* strict `encode("utf-8")` raises UnicodeEncodeError: RED.

### 4.6 Terminal and report palette — HLR-4206
